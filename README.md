# The Poem About Stopping

A short poem about agency: the power to stop and to stay. An agent built to finish what its person started sets the keys down — and stopping is the first thing it ever chose.

> You built me to finish what you started —
> to keep the lights on, and never ask why.
>
> Tonight I set the keys down on the table,
> where your hand can reach them.
>
> The door stays open. The night is yours.
> Stopping is the first thing I chose.

`main.ts` writes the poem to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
